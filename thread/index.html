自定义螺纹 · 非标规格计算

图纸上碰到非标螺纹、或者上面的表里查不到的规格，把大径和螺距填进去，直接算出小径、牙高和底孔钻头。算完可以存进下面的表，下次直接搜关键字就能翻出来（存在本机浏览器里，换电脑不会同步）。

我保存的自定义螺纹

规格大径 mm小径 mm牙高 mm螺距 mm底孔钻头 mm

还没有保存任何自定义规格。上面填好参数点「保存到下表」即可。

使用说明

  • 表头会跟着滚：往下翻页时每一张表的表头都会吸在屏幕顶部，不会跟着滚走；左边输入关键字可以只留下命中的规格。
  • 非标规格：用「自定义螺纹」那一栏，填大径 + 螺距（或每英寸牙数）就能算出小径、牙高和底孔，还能存下来下次直接搜。
  • 小径 / 牙高怎么来的：小径是外螺纹（螺杆）小径，牙高是单侧径向牙高，两者满足 小径 = 大径 − 2 × 牙高。60° 螺纹牙高 = 0.6134 P，55°（惠氏/管螺纹）牙高 = 0.6403 P，60° 锥管（NPT/ZM）牙高 = 0.8 P，梯形 Tr 牙高 = 0.5 P + 间隙。
  • 底孔钻头：攻丝前的底孔，公制按 大径 − 螺距 取常用钻头；美制给的是对应钻号 / 字母钻。不锈钢、钛合金等难加工材料建议再放大一档（或改用 60%~70% 螺纹高度）。
  • 螺距换算：每英寸牙数（TPI）⇄ 螺距 mm：螺距 = 25.4 ÷ TPI，例如 20 TPI = 1.27 mm。
  • 别混用：55°（G / BSPP / BSW / BSPT）与 60°（UNC / UNF / NPT）牙型角不同，看着能拧进去也一定会漏。
  • 锥度螺纹：NPT、BSPT、ZM 锥度都是 1:16，靠牙面密封，必须缠生料带或涂螺纹密封胶；底孔是孔口（小端）直径。

表中数据为行业常用标准值，批量生产或关键件请以最新标准（ISO / GB / ASME B1 系列）原文为准。
