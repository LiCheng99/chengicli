## 0. 先明确边界

| 类型 | 能不能自己控制 | 做法 |
|---|---|---|
| 脚本 / 样式 / 字体（每页 21 个请求） | ✅ 能，100% | 下载进 `source/`，配置改本地路径 |
| 图片（封面 / 背景 / 页脚徽章） | ✅ 能，100% | 存进 `source/assets/`，代码引用本地文件 |

## 5. 阶段四：监控（约半小时，这才是「控制坏不坏」的仪表盘）

自托管后剩下会坏的就三类：你自己的域名 / Vercel 构建 / 动态接口。写一个 `tools/link-check.mjs`：

1. 读 `public/**/*.html`，抓所有 `src` / `href` / `url()` 里的 **站内** 绝对路径 → 逐个 `HEAD`，400/500 即报错（防止你哪天删图删出死链）；
2. 另外维护一份「动态接口清单」（hitokoto / ip / QQ 音乐 / deepseek），逐个探活；
3. 输出一张表：正常 / 慢（>2s）/ 失败，失败项直接列出文件与行。

跑法放在 `package.json`：`"check:links": "node tools/link-check.mjs"`，每周手动跑一次，或者挂 GitHub Actions 定时任务。

## 8. 本地化之后的残余风险（重要，别以为就此 100%）

「全部下载到本地」解决的是**外部依赖**这一层：文件在你仓库里，别人删不了、限流不了、墙不了。
但风险不会消失，只会**转移**——从「别人随机决定」变成「你自己犯错的概率」。

| 还会让页面坏的原因 | 怎么防 |
|---|---|
| **大小写**：Windows 本地不区分，Vercel（Linux）区分 | 路径和文件名**全小写**；统一用绝对路径 `/js/lib/vendor/...`，别用 `../` |
| **忘了提交**：文件生成了但没 `git add`，构建机上没有 | `hexo generate` 后确认 `public\js\lib\vendor\` 里真有这些文件 |
| **构建链二次处理**（见 8.1） | 在 `gulpfile.js` 里把 vendor 目录排除 |
| **相对引用没跟着拷**：fontawesome 的 `../webfonts/`、lxgw 的 `./files/` | 保持目录结构，别只拷 CSS 文件 |
| **改了文件但没提 `?v=`**：老访客拿缓存里的旧引用 | 配置里凡是 `/js/...?v=` 的，改完手动 +1 |
| **仓库 / 平台本身**：Vercel 构建失败、域名解析、误删文件 | 你自己的账号，可控、可回滚（git） |
| **动态接口**：一言 / QQ 音乐 / IP 定位 | 搬不走，只能照第 4 节做降级 |
| **正文里引用别人的图 / 友链 / 导航站** | 搬不走，只能靠 link-check 定期发现 |

### 8.1 你这套构建链的三个坑（已核对 `gulpfile.js`）

1. **`compress` 会重压所有 `public/**/*.js`，但跳过 `*.min.js`**（第 19 行）。
   → vendor 文件尽量保留 `.min.js` 后缀；`fancybox.umd.js`、`issues.js`、`wow_init.js` 这几个会被 terser 二次压缩，多数没事，但压第三方 UMD 偶有翻车。
2. **`minify-css` 用 `compatibility: 'ie11'` 重压所有 `public/**/*.css`**（第 32–40 行），包括 FontAwesome 和霞鹜文楷的 CSS。
   → 建议在两条 `gulp.src` 数组里各加一行 `'!./public/js/lib/vendor/**'` / `'!./public/css/lib/vendor/**'`。
3. **`minify-html` 开了 `minifyURLs: true`**（第 59 行），会改写页面里的 URL。
   → 对 `/` 开头的绝对路径安全，这也是要求「统一用绝对路径」的另一个原因。

> 好消息：`pwa.enable` 是 **false**（`_config.fomalhaut.yml` 第 1161 行），没有 Service Worker 缓存旧外链的问题，改完访客刷新就能拿到新版本。

## 9. 自托管会不会变慢（实测账本，2026-10-31）

**结论：不会更慢，但也不会明显更快。** 字节数一点没变，变的只是「从几个域名拿」变成「从自己的域名拿」。

### 9.1 现在一页到底多大（`public/index.html` 实测）

| 项目 | 数量 | 体积 |
|---|---|---|
| HTML 本体 | 1 | 59.9 KB（brotli 后约 12 KB） |
| 站内 js/css | **67 个文件** | **802 KB** |
| 外部 js/css | 21 个请求 / 5 个域名 | **209 KB** |
| 字体（霞鹜文楷按 unicode-range 实际下载） | 约 21 个分片 | 480–700 KB |
| 图片 | 10 个（全部懒加载） | 按需 |

> 外面那 209 KB 只占全站 **20%**。所以「把外链搬进来」不会让页面变重——总量一样，域名从 5 个降到 1 个。

### 9.2 为什么域名少反而快

首屏每开一个新域名要付 **DNS + TCP + TLS ≈ 1.5 个 RTT**，5 个外部域名 ≈ 额外 5 次建连；搬进本地后全部走同一条 HTTP/2 连接（自己域名那条本来就建好了）。

你现在的 `preconnect` 已经预热了其中 4 个（`_config.fomalhaut.yml` 1184–1187、1200–1201），所以这部分收益没有想象中大——**真正的收益是「不再依赖别人是否抽风」**：`cdn.jsdelivr.net` 在国内经常 1 s 以上甚至超时，那 29.6 KB 的字体 CSS 会直接卡住渲染。

### 9.3 真正在拖慢你的三件事（跟自托管无关，现在就存在）

1. **`vercel.json` 里没有任何缓存头** —— 默认 `must-revalidate`，67 个站内 js/css **每次访问都要回源确认**。这是最大的一笔冤枉开销。
2. **字体 480–700 KB / 页**，是单项最大；388 个分片文件全进部署包。
3. **图片没做 webp / 宽度限制**，picsum 原图 1200×675 JPEG 直接上。

### 9.4 给 `vercel.json` 加缓存头（复制即用）

```json
  "headers": [
    {
      "source": "/js/(.*)",
      "headers": [{ "key": "Cache-Control", "value": "public, max-age=31536000, immutable" }]
    },
    {
      "source": "/css/(.*)",
      "headers": [{ "key": "Cache-Control", "value": "public, max-age=31536000, immutable" }]
    },
    {
      "source": "/assets/(.*)",
      "headers": [{ "key": "Cache-Control", "value": "public, max-age=31536000, immutable" }]
    }
  ]
```

配 `immutable` 的前提是**改文件必提 `?v=`**（你现在的配置里大部分已经这么做了）。
html 不配，交给 Vercel 默认的 `must-revalidate`，保证改版立即生效。

同时给图片加 `loading="lazy"` + `width` / `height`（现在是 `data-lazy-src` + 占位 gif，宽高缺失会抖）。

### 9.5 国内访问的现实预期

| 来源 | 国内典型 TTFB |
|---|---|
| npmmirror / elemecdn / baomitu（国内 CDN） | 30–80 ms |
| cdn.jsdelivr.net | 200 ms – 3 s（不稳定） |
| Vercel 香港节点（hkg1） | 60–150 ms |

搬进本地后，那 209 KB 从「国内 CDN 30 ms」变成「Vercel 香港 80 ms」——**单请求略慢 50 ms，但省掉 4 次 TLS 建连（每次 100–300 ms）**，首屏大致打平或略好；重复访问因为能配 `immutable`，会明显更快。

想让国内更快只有一条路：**国内 CDN + 已备案域名**（七牛 / 又拍 / 阿里云 OSS + CDN）。这是另一件事，跟自托管不冲突——文件在自己仓库，随时可以再推一份到国内 CDN。

### 9.6 别猜，测

```powershell
# 单页 TTFB 与总耗时（多跑几次取中位数）
curl.exe -o NUL -s -w "ttfb=%{time_starttransfer}s total=%{time_total}s size=%{size_download}\n" https://你的域名/
```
