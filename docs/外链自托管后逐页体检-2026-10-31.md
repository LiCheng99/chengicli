## 追加：用户报的三个页面问题（2026-10-31 晚）

### 1. `/archives/` 布局贴边 —— 真 bug，已修

**现象**：归档卡片里的内容紧贴左右边缘，分页贴在卡片底边。

**根因**：`themes/fomalhaut/layout/archive.pug` 把两个标签发在了 `<main class="layout">` 里、`#archive` **之前**：

```pug
link(rel='stylesheet' href=...archive-page.css...)
script(defer data-pjax src=...archive-page.js...)
#archive
```

主题给正文根设内边距靠的是 `.layout > div:first-child:not(.recent-posts){padding:50px 40px}`。
`<link>` 一旦排在前面，`#archive` 就不是 `:first-child`，这条规则整体失效 → padding 从 `50px 40px` 变 `0`。

用 CDP 读计算样式可以确认：

| | padding | `#archive` 是首个子元素 | `#archive` 高度 |
|---|---|---|---|
| 修复前 | `0px` | ❌（前面有 LINK、SCRIPT） | 1060 |
| 修复后 | `50px 40px` | ✅ | 1160 |
| 旧站（对照） | `50px 40px` | ✅ | 1160 |

**修法**（两层）：
1. `archive.pug`：`<link>` 挪到 `#archive` **之后**；删掉重复的 `<script>`（它本来就在 `inject.bottom` 全局加载，等于执行两遍）。
2. `archive-page.css`：给 `#archive/#category/#tag` 显式补回 `padding:50px 40px`（移动端 `36px 14px`），以后 DOM 顺序再变也不会再丢。

### 2. `/music/` 向上滚菜单不回来 —— 已加兜底

**根因**：歌单 `#mp-list` 是个固定 460px、自身可滚的容器（`scrollHeight 1458 > clientHeight 460`）。
鼠标在歌单上向下滚到容器底时，「滚动链」把剩余滚动传给 `window` → `nav.js` 判定向下滚、收起菜单；
反过来向上滚时只滚容器、`window.scrollTop` 不变 → `scroll` 事件不触发 → 菜单永远不回来。

> 说明：新旧两版的 CSS/JS/DOM 在这块**完全一致**（`hexo-1` 与当前文件逐行相同，`#mp-list` 的 `maxHeight:460px / overflowY:auto` 也一样），
> 所以这不是外链本地化引入的；但既然体验确实会卡住，我加了修复。

**修法**：`nav.js` 里补一个 `wheel` 监听（wheel 会冒泡到 window，scroll 不会）——向上滚就恢复菜单并同步 `position`。

验证（CDP 真实滚轮事件）：滚到 900px → 菜单 `display:none`；在歌单上向上滚 3 次 → 菜单恢复 `display:block`。

### 4. 顺带发现：归档页脚本被加载两次

`archive.pug` 里的 `archive-page.js` 与 `_config.fomalhaut.yml` 第 1148 行的注入重复 → 已删掉模板里那份，现在每个归档页只出现 1 次。
