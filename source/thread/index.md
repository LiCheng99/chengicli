  <h2>使用说明</h2>
  <ul>
    <li><b>表头会跟着滚</b>：往下翻页时每一张表的表头都会吸在屏幕顶部，不会跟着滚走；左边输入关键字可以只留下命中的规格。</li>
    <li><b>非标规格</b>：用「自定义螺纹」那一栏，填大径 + 螺距（或每英寸牙数）就能算出小径、牙高和底孔，还能存下来下次直接搜。</li>
    <li><b>小径 / 牙高怎么来的</b>：小径是<b>外螺纹</b>（螺杆）小径，牙高是单侧径向牙高，两者满足 <code>小径 = 大径 − 2 × 牙高</code>。60° 螺纹牙高 = 0.6134 P，55°（惠氏/管螺纹）牙高 = 0.6403 P，60° 锥管（NPT/ZM）牙高 = 0.8 P，梯形 Tr 牙高 = 0.5 P + 间隙。</li>
    <li><b>底孔钻头</b>：攻丝前的底孔，公制按 <code>大径 − 螺距</code> 取常用钻头；美制给的是对应钻号 / 字母钻。不锈钢、钛合金等难加工材料建议再放大一档（或改用 60%~70% 螺纹高度）。</li>
    <li><b>螺距换算</b>：每英寸牙数（TPI）⇄ 螺距 mm：<code>螺距 = 25.4 ÷ TPI</code>，例如 20 TPI = 1.27 mm。</li>
    <li><b>别混用</b>：55°（G / BSPP / BSW / BSPT）与 60°（UNC / UNF / NPT）牙型角不同，看着能拧进去也一定会漏。</li>
    <li><b>锥度螺纹</b>：NPT、BSPT、ZM 锥度都是 1:16，靠牙面密封，必须缠生料带或涂螺纹密封胶；底孔是孔口（小端）直径。</li>
  </ul>
